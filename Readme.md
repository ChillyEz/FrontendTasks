# Dota 2 Wiki

A responsive Dota 2 Wiki website created as a Front-End Web Technologies project.

## Pages

The website contains four main pages:

- **Home** (`index.html`) — main page with general information about Dota 2.
- **Heroes** (`heroes.html`) — list of heroes with search and filters.
- **Items** (`items.html`) — collection of Dota 2 items with item information.
- **Esports** (`esports.html`) — information about Dota 2 esports and The International.

## Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Features

- Responsive design for desktop, tablet and mobile devices
- Bootstrap Grid and responsive utilities
- Responsive Bootstrap Navbar with hamburger menu
- Bootstrap Buttons and Button Groups
- Bootstrap Carousel
- Bootstrap Cards
- Bootstrap Forms
- CSS Media Queries
- Hero search and filtering
- Semantic HTML and accessibility features
